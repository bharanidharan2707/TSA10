# All-in-One Text and Speech Analyzer

## About

An AI-powered application that combines multiple text and speech analysis features in one platform.

## Features

* Sentiment Analysis
* Speech-to-Text
* Text-to-Speech
* Speech Emotion Detection
* Spam Detection
* Text Summarization
* Speech Translation
* Grammar Checking

## Technologies

* Python
* Machine Learning
* NLP
* Speech Recognition
* Streamlit
* SQLite

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
